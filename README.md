# 货币战争策略"人脉进阶"羁绊求解器

## 用途：用于求解棱彩投资策略"人脉进阶"各人口数下的最优配队以及最优的过渡链
推荐使用梦转那刻夏，三人口战力就够用

**没有release，直接下载代码运行**

> 数据版本：**v4.7**（货币战争·入画奇航）。赛季数据已硬编码进 `data_v47.py`，**不需要任何外部 JSON 文件**，下载即用。

**一键运行**：双击 `run.bat`（或 `python run_all.py`），配置直接写在 `run_all.py` 顶部的 `CONFIG` 里：

```python
CONFIG = {
    "data": "",                        # 留空 = 用内置数据；填路径 = 读外部赛季 JSON
    "required": ["花火", "刻律德菈", "那刻夏"],   # 必带角色
    "emblems": {"那刻夏": ["梦境交织"]},          # 转职
    "independent": ["双龙吟", ...],               # 不计入的独立羁绊
    "trait_rules": {"少女乐队": {"exact": [1, 4]}, "千星商会": {"min": 2}},
    "cost_caps": {"7": 3, "8": 4, "9": 5, "10": 5, "11": 5},
    "run_teams": True, "max_k": 14, "include_next": True,
    "run_transition": True, "trans_from": 7, "trans_to": 11, "trans_top": 3,
    "out_dir": "输出",
}
```

结果统一写到 `输出/`（`answer.*` 与 `transition.md`）。只想试跑一下：`run.bat --quick`。

---

两个底层程序共用 [cwmodel.py](cwmodel.py)（模型 + 规则 + 枚举器），数据来自 [data_v47.py](data_v47.py)：

| 程序 | 作用 |
|---|---|
| [solve_teams.py](solve_teams.py) | 给定必带角色，求 k=3..14 个羁绊时上场人数最少的队伍（最优 + 次优） |
| [transition_teams.py](transition_teams.py) | 求 7→8→9(→10→11) 人口的同核心、零换人过渡链 |

## 角色名里的「点」

数据里有 **6 个角色名带点**：**丹恒•饮月、丹恒•腾荒、千冶•刃、姬子•启行、砂金•戏浪、知更鸟•晴歌**。

原始数据用的是 U+2022（`•`，BULLET），Windows 的 GBK 控制台无法编码，直接打印会抛 `UnicodeEncodeError`。
所以程序加载数据时会统一替换成 U+00B7（`·`，MIDDLE DOT）：

- 程序输出里看到的是 `丹恒·饮月`、`千冶·刃` 这种写法；
- `--require "千冶·刃"` 和 `--require "千冶•刃"` 都能识别（加载时会归一化）。

## 可配置项

```bash
# 必带角色（默认 花火,刻律德菈,那刻夏）
python solve_teams.py --require "花火,翡翠"

# 转职星徽（默认 那刻夏=梦境交织），可重复
python solve_teams.py --require "花火,翡翠" --emblem "翡翠=梦境交织"

# 整体规则文件
python solve_teams.py --config cfg.json

# 换赛季数据（可选，默认用内置的 v4.7）
python solve_teams.py 新赛季.json
```

`cfg.json` 示例：

```json
{
  "required": ["花火", "刻律德菈", "那刻夏"],
  "emblems": {"那刻夏": ["梦境交织"]},
  "independent": ["双龙吟","盗火行者","巡海游侠","黑市主理人","机心巧匠","幻乐之主"],
  "trait_rules": {"少女乐队": {"exact": [1,4]}, "千星商会": {"min": 2}},
  "cost_caps": {"7": 3, "8": 4, "9": 5, "10": 5, "11": 5}
}
```

内置规则（本次修正）：

- **千星商会：1 人不生效，≥2 人才算激活**（原数据阈值写的是 1，实际不是）。
- 少女乐队：仅恰好 1 人或恰好 4 人激活。
- 独立羁绊（双龙吟、盗火行者、巡海游侠、黑市主理人、机心巧匠、幻乐之主）不计入激活羁绊数。
- 那刻夏携带【梦境交织星徽】→ 额外 +1 个梦境交织计数。

## 结论（默认配置：花火 + 刻律德菈 + 梦境交织那刻夏）

| k | 最优人数 | 最优队数 | 次优人数 | 次优队数 |
|---|---|---|---|---|
| 3 | 3 | 1 | 4 | 48 |
| 4 | 4 | 11 | 5 | 669 |
| 5 | 5 | 66 | 6 | 5075 |
| 6 | 5 | 2 | 6 | 489 |
| 7 | 6 | 3 | 7 | 2539 |
| 8 | 7 | 59 | 8 | 15090 |
| 9 | 7 | 1 | 8 | 448 |
| 10 | 8 | 2 | 9 | 2756 |
| 11 | 9 | 33 | 10 | 15788 |
| 12 | 10 | 201 | 11 | 79308 |
| 13 | 11 | 1245 | 12 | 354844 |
| 14 | 11 | 8 | 12 | 7206 |

最优合计 1632 队，次优合计 484 260 队。与人口上限对照：9 人口最高 11 羁绊、10 人口 12 羁绊、11 人口 14 羁绊。

## 过渡链（默认配置，11 人口收尾）

7 → 8 → 9 → 10 → 11 的羁绊数：**7 → 9 → 11 → 12 → 14**

- 7 人口：花火、刻律德菈、那刻夏、火花、真珠、开拓者·欢愉、银狼LV.999
- 8 人口：+砂金
- 9 人口：+知更鸟•晴歌
- 10 人口：+丹恒•饮月
- 11 人口：+景元

完整结果由程序运行时生成（9/10/11 人口三组各 3 条路线）。

## 单独运行（不用一键脚本时）

```bash
cd 货币战争工具
python solve_teams.py              # 用内置数据
python transition_teams.py         # 同上
python solve_teams.py 新赛季.json   # 也可以指定外部数据文件
```

（三个 .py 必须在同一目录，`solve_teams.py` / `transition_teams.py` 会 `import cwmodel`。）

## 排序

- 队伍内：必带角色置顶，其余按费用升序（同费按名字）。
- 队伍之间：按最高费用升序，同高再比次高，最后按名字。

## 验证

Python 枚举曾与独立 C 暴力枚举逐项对拍（旧口径下完全吻合）；修正「千星商会 ≥2 人才生效」后，
配队结果与过渡链的人口上限互相一致（9 人口 11 羁绊、10 人口 12 羁绊、11 人口 14 羁绊）。
